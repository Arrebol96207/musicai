# Local Music

Put your own real audio files here. Claudio Music will scan this folder automatically.

Supported extensions:

```text
.mp3 .wav .ogg .m4a .aac .flac
```

Examples:

```text
music/01. song.flac
music/my-track.mp3
```

There is no synthetic audio fallback. If online search fails, local files here remain playable.
